# ことばクエスト PC／ブラウザ版 VETA11

本版は **VETA10 PC版** からの差分です。モデルファイルや既存の画像・手書き認識エンジンは変更していません。

## 概要

- 7つのジャンルカードに「ジャンル Lv.1〜10」の表示を追加。ジャンルの数値は課題ごとの達成レベルから算出します。
- 各課題にLv.1〜10の難易度選択欄。未達成の難易度も任意選択できます。既存の記録を削除・初期化しません。
- 課題ごとに **0〜100ポイント** の熟練度を独立して保存。完了で5ポイント、正答率による追加は最大15ポイント。レベルの熟練度100に到達すると次が開放。Lv.10が上限。
- 問題の抽選は選択した難易度の問題を優先。1セッションは設定により原則5〜20問（会話クイズ5問、3D4問、朗読5問、構音ナビ5問など従来の固有仕様を優先）。
- **通常課題22種類** に、それぞれ内容に沿った100件の問題候補を追加。既存問題も保持。発音トレーニングの専用画面にも100件の語彙・短文課題を追加。AI会話の5問クイズにも100件を追加。
- 3Dピクトグラム判断クイズ：従来20件＋新規80件＝100件。ダッシュ移動・メダル報酬を維持。
- 朗読・記憶：3物語それぞれ従来20件＋新規15件＝35件。**ジャンル合計105件**。本文と矛盾しない内容に限定。
- ことばファンタジーDX：従来31件＋新規80件＝111件。専用レベルの選択内容を出題へ反映。
- トレーニング記録、1日／月間Excel、問題別結果に難易度・熟練度を保存／出力。

## 素材上の制約と注意

「100問」は**問題データのバリエーション数**です。とくに「写真を見て動作を答える」「文字・画像マッチング」「画像の呼称」では、**100枚の異なる画像を新規作成したわけではありません**。画像を使う課題は既存のJPG素材を繰り返し用います。実際に100種類の別画像を必要とする場合は、画像素材の追加と各問題の再監修が必要です。

「構音筋ビジュアルナビゲーション」は6種類の構音群と既存の28音の資料を尊重し、毎回5問を抽選します。根拠のない100種類の異なる構音部位は作りません。「ことばダンジョン」の育成EXPは独立した既存仕様として維持し、今回の共通熟練度への自動統合は行いません。

本アプリは学習・コミュニケーション練習用です。Lvと熟練度は医学的な機能評価ではありません。手書き・発音の判定精度は端末・ブラウザ環境に依存します。

## 運用方法

1. ZIPファイルを展開し、`index.html` と関連フォルダを**同じディレクトリ構成**でWebサーバーへアップロードしてください。
2. ブラウザで「始める」→ジャンル→課題の「難易度」を選び→課題ボタンを押します。
3. トレーニング完了後、結果画面に熟練度が表示されます。記録画面とExcelにも保存されます。
4. 前の版の記録は同じブラウザ・同じオリジンの保存先から読み込みます。別URL・別パスでの動作を保証するものではありません。公開前にバックアップをおすすめします。

## 検証

`node tests/verify-veta11.cjs` で問題データ件数・レベル分配・熟練度保存・リンク参照を確認できます。実機ブラウザと音声・手書き・3D表示の通し操作は別途確認してください。
