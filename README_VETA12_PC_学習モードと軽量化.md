# ことばクエスト VETA12｜PC・ブラウザ版

## 今回の変更点

- 設定の「🧠 学習モード ON / OFF」**1つ**で学習分析の有効・無効を切り替えます。変更後は画面の「再読み込み」を押してください。
- ON：各ジャンルの判定済み回答、ことばファンタジーDX、ピクトグラム3D、ことばダンジョンの回答傾向を端末内で集計。正誤から確率的な習熟推定（簡易BKTモデル）を更新します。
- ON：直近の苦手問題を復習候補へ優先し、各課題で同じ難易度の判定済み回答が5問以上あるとき「おすすめ Lv.」を参考表示します。
- OFF：確率分析・復習優先は休止。**通常の練習、任意Lv.1〜10、既存の熟練度、メダル、通常のトレーニング記録は継続**します。
- どちらのモードでも過去の記録・問題・認識エンジン・モデルは削除しません。設定は利用者プロフィール別に保存します。
- 学習結果の表示とExcel出力に「学習推定（参考）」を追加しました。分析対象の回答がない記録は「—」です。

## 軽量化

1. PC版の初回起動では、写字・見写し専用の7本の補助スクリプトを読み込みません。**写字・見写し開始時だけ**既存データを読み込みます。
2. キャッシュ初期登録は画面表示に必要なファイルへ絞りました。大量の問題写真・BGM・OCRなどは使用時に読み込み、その後キャッシュされます。
3. BGMの先行読み込みを抑止しました。学習モードOFF時は確率分析の保存・計算を行いません。
4. **元の画像、学習問題、音声、OCRエンジン・モデルはそのまま保管**しています。動作の互換性を優先したため、ZIP自体の大幅な縮小は行っていません。

## 必ずご確認ください

- 初回の「写字・見写し」は認識コードの読み込みに数秒かかる場合があります。初回読み込み前にオフラインになると一部の写真やOCRが表示できない可能性があります。
- 「習熟推定」は学習支援のための参考値であり、医学的診断・治療効果の評価には用いないでください。音声の自己評価（「できた」等）は、正誤が客観的に採点された回答として扱いません。
- プロフィール情報と学習記録はブラウザのローカルストレージに保存されます。ブラウザの保存データを消すと失われる可能性があります。重要な記録はExcel等に書き出してください。
- 他の端末との同期機能は追加していません。以前のバージョンの保存データを残した同じブラウザで使ってください。
- GitHub Pagesへの反映は行っていません。公開する場合は **フル版ZIPを展開してファイルをアップロード**、既存版から更新する場合は **差し替えZIPの中身だけを上書き**してください。ZIPファイルそのものをGitHub Pagesに置くだけでは展開されません。

## ファイル

- `*_full.zip`：動作に必要なPC・ブラウザ版の全ファイル。
- `*_patch.zip`：VETA11 PC版から変更・追加したファイルのみ。ディレクトリ構成を維持して上書きしてください。

## 動作確認

`node tests/verify-veta11.cjs` で既存の100問×22課題とLv.1〜10を検証。
`node tests/verify-veta12.cjs` で学習モード切り替え、プロフィール別の分析、既存記録保持、HTML参照を検証。
実機ブラウザでの手書き認識・マイク認識および3Dグラフィックスは別途確認が必要です。
