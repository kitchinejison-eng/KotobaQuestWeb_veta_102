# ことばクエスト VETA8｜PC・ブラウザ版

## 今回の更新

- Android版 VETA7 の共通処理を照合し、PCでも使える「手書き候補から選択した回答」の記録を統合しました。
- 「写字・見写し」で書き終えてから約4.8秒間操作がない場合、認識候補が自動表示されます。「文字の候補を見る」ボタンは不要です。
- 利用者が候補を選び「この文字で回答する」を押した場合にだけ見本と照合します。
- トレーニング記録に、選択回答の方式と認識エンジンの初期候補を記録できるようにしました。
- 画像を同じ寸法のままWeb向けJPEGに圧縮し、画面の表示内容を維持しつつ転送容量を軽くしました。
- オフラインキャッシュの初回保存を6件ずつ処理するようにし、アクセス集中を抑えました。対象画像の事前保存は維持しています。
- 開発・履歴用のファイル、PCで参照されない旧Android単体スクリプト、重複した設定ファイルを配布物から取り除きました。

## モデルについて

手書き用の **JLect JHR** と既存の補助OCR・AIモデルは変更していません。
Android版 VETA7 の Google ML Kit はAndroidネイティブ専用です。Android側のモデル一括ダウンロード画面・ブリッジは、PCブラウザには移していません。

認識候補から正解を選べたことと、手書き自体の形が正しかったことは別です。練習結果の表示・採点はこの区別を維持しています。

## 使い方

1. ZIPを解凍し、`index.html` を開いてください。GitHub Pagesでは、ZIP内のファイルをリポジトリの公開ディレクトリへ配置してください。
2. 「認知・理解トレーニング」→「写字・見写し」で文字を書き、認識候補が出るのを待ってください。
3. 候補を選んで回答を確定します。記録の「問題ごとの結果」に回答方法を表示します。

マイク・オフライン保存・一部のAI機能はHTTPSまたはlocalhost環境が必要です。JPEGを再圧縮しているため、画像の見た目にはわずかな差が生じる場合があります。
