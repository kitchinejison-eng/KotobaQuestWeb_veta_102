# ことばクエスト PC・ブラウザ版 VETA9

## 変更点

1. ピクトグラム3Dクイズは、移動中いつでも従来のダッシュ速度（12.5）で進むようにしました。通常歩行（速度7）とShiftキー／タッチ用ダッシュボタンは廃止しました。ジャンプ・視点操作・一時停止・メダル獲得・学習記録は維持しています。
2. タイトル画面と設定画面に「プロフィールを見る」導線を追加し、表示名、任意の管理番号、プロフィール登録日、トレーニング記録の件数、メダル数を表示します。
3. プロフィール画面から既存の「ユーザー設定」を編集でき、保存・キャンセル後はプロフィールへ戻れます。設定画面から直接編集する操作も引き続き使えます。
4. プロフィールと学習記録の保存先は従来と同じブラウザ内のストレージです。既存データや手書き・AIモデルは変更していません。

## ご利用方法

- 新しく設置するときはPC版のZIPを展開し、ファイルをWeb公開ディレクトリに配置してください。
- 既にVETA8を使用中であれば「GitHub差し替え版」のファイルを同じ場所へ上書きしてください。
- 変更内容がすぐ表示されない場合はページを再読み込みしてください。Service Workerのキャッシュ名は更新済みです。
- HTTPSまたはlocalhostでの利用を推奨します。

プロフィール情報は端末内だけに保存され、自動的に別端末と同期されません。
