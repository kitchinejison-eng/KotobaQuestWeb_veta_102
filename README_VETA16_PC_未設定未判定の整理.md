# ことばクエスト VETA16｜PC・ブラウザ版

VETA15の追加修正版です。アプリの画面構成・3Dクイズ・ダンジョン・ガチャ・熟練度など、VETA15の機能をそのまま引き継ぎます。

## 「未設定」「未判定」について

VETA15で確認した「未設定」23箇所と「未判定」6箇所は、**ソースコードにある文字列の出現数**です。未完成の問題がその数だけあるという調査結果ではありません。

本版では、通常画面・記録・Excel出力で意味が不明瞭にならないよう表示と記録処理を修正しました。

| 以前の曖昧な表示 | VETA16の表示・処理 |
|---|---|
| ユーザー未設定 | 「名前未登録」など、欠けている情報を具体的に表示 |
| 管理番号未設定 | 「登録なし（任意）」と明記 |
| 登録日未設定 | 「登録日なし」と明記 |
| 回答していない問題 | 「未回答」（正解・不正解を捏造しない） |
| 自分で飛ばした問題 | 「スキップ」 |
| ゲームオーバー後の残りの問題 | 「未出題」 |
| 古い記録にある「未判定」 | 出力時に「未回答」などへ表示変換。過去の原データは変更しない |

以前の文字列のうち、残存する「未設定」3箇所・「未判定」2箇所は旧データを識別・読み替えするために使用します。これは実際の未入力・未採点の件数ではありません。

## 重要な判定経路の修正

**端末内AIクイズ**で正解した場合、以前は点数に反映されても個々の問題の正誤記録が保存されない経路がありました。VETA16では、正解・不正解の回答文字列、正誤、回答方式を共通記録へ渡します。初回不正解後に正解した場合は「復習後正解」と表示し、確率的な熟練度分析には初回の判定のみを使います。

**未回答・スキップ**は正答として扱いません。通常の正答率の分母には出題数として含まれますが、学習モードの確率的な熟練度分析には、実際に正誤が判定された回答だけを記録します。

**プロフィール登録**では、過去バージョンの「未設定」状態を登録済みと誤認しないように調整しました。未登録の方は初回登録から進み、登録時には固有のプロフィールIDを発行します。

## 保存データと対応範囲

- トレーニング記録、プロフィール、熟練度、所持メダル、着せ替えの保存キーは変更しません。
- 過去記録の削除・一括書換えは行いません。
- 新版のキャッシュを認識できるよう更新しています。
- **PC・ブラウザ版のソースZIP**です。Android APKの生成と実機テストは今回の配布物に含まれません。
