# ことばクエスト PC／ブラウザ版 VETA13

この版は VETA12 の PC／ブラウザ版をベースに、**コトバ・ダンジョンのホーム画面**と**ことばファンタジーの会話イベント**を調整したものです。

## 主な変更

1. コトバ・ダンジョンのホーム画面を、提供画像を参考にしたパステルカラーの縦長・ドット絵風メニューへ変更。
2. 中央のキャラクターと上部プロフィールの画像には、現在選択中のアバターを連動表示。着せ替え・アバター変更・ガチャの保存データは従来どおり使用。
3. メダル・ガチャゲージ・ダンジョン挑戦・トレーニング記録・アバター着せ替え・最近の冒険・ホーム・設定を配置。中央の部屋背景は CSS 描画で、画像データの追加を抑制。
4. ことばファンタジーの会話イベント開始時に、未定義変数を参照して進行できなくなる不具合を修正。
5. 会話の進行表示・次へボタン・途中スキップを整備。二重進行を防ぐ保護を追加し、PC、縦向き、横向きの表示を調整。
6. 既存のレベル・熟練度・学習モード ON/OFF、問題集、トレーニング記録、利用者プロフィール、メダルなどは維持。

## 軽量化の方針

- 追加したメニュー装飾は CSS を中心に実装し、新しい背景画像・動画・外部ライブラリを増やしていません。
- 既存の必要なアバター画像のみを利用します。
- VETA12 のリソース遅延読み込みとキャッシュ方針を維持し、キャッシュ名だけ VETA13 に更新しています。

## 導入・動作確認

- **フル版 ZIP**：新規の GitHub Pages 公開先には展開した中身を配置してください。
- **差し替え ZIP**：VETA12 に対して同名ファイルを上書きし、新規 CSS を追加してください。元データのバックアップを推奨します。
- 公開更新後、ブラウザーのキャッシュが残る場合はページを再読み込みしてください。
- 確認項目：選択アバター・着せ替え反映、メダル／ガチャ、冒険開始、会話イベントの途中スキップ、画面の縦横切り替え、記録の閲覧。
