# ことばクエスト PCブラウザ版 VETA10：問題数の調整

既存のVETA9をベースに、問題数の少なかった課題の問題候補を増やしました。
音声・手書き認識モデル、利用者プロフィール、3D常時ダッシュ、学習記録の保存形式は変更していません。

**通常のトレーニング**は、ユーザー設定の問題数（5・10・15・20問）に合わせて登録問題から選択します。

- **3Dピクトグラム**：20問の候補から1回4問を選択（報酬ルールは変更なし）。
- **朗読・記憶**：各物語の候補20問から1回5問をランダム選択（長時間の問題数増加を防止）。
- **構音筋ビジュアルナビゲーション**：元から6種類の発音グループから動的に出題されるため、5問／回の仕様を維持。
- **その他の課題**：元の出題数・モデル・進行方法を維持。

「聞いて選ぶ」は既存の画像素材のみを使用し、「指示を理解する」は既存の動作画像と新しい音声指示の組み合わせを使用します。読み上げ内容が正解の表示にならないようにしています。

- 実端末のマイク認識・3D描画・全課題の操作は、公開先のPCやタブレットでの確認が必要です。
