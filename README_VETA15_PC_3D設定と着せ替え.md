# ことばクエスト VETA15｜PC・ブラウザ版

VETA14をベースにした追加修正版です。既存のプロフィール、トレーニング記録、熟練度、ダンジョンの所持メダルや衣装データは初期化しません。

## 今回の修正

1. **3Dピクトグラム○×クイズ**
   - 「ゲームスタート」ボタンを廃止し、3Dの読み込み完了後に自動開始します。読み込みに失敗した場合のみ「再読み込み」を表示します。
   - 問題数を **5・10・15・20問** から選択できます。初回は5問、全体設定で問題数が保存済みならその値を引き継ぎます。3D内で一度選んだ問題数は次回以降も保存されます。
   - 3D内の「一時停止・設定」から問題数や解放済み難易度を変えられます。次回開始に反映され、すぐにやり直す「設定を反映して再挑戦」も使えます。
   - 正答率・メダル・熟練度・学習記録・画面内の進捗表示は、実際に出題した問題数を基準に計算します。
   - **難易度ごとの問題は原則10種類**のため、15問・20問を選んだ場合は同じ難易度の問題を「【復習】」として再出題します。未解放の高難易度問題は混ぜません。
2. **ジャンル画面**：「⚙️」アイコンに「設定」の文字を追加しました。
3. **ことばダンジョン／着せ替え**：衣装の表示をアバターの身体に合わせて配置し、現在装備中の衣装名と「✓ 装備中」を表示します。モバイル画面では衣装選択を2列にして押しやすくしました。
4. **保存とキャッシュ**：問題数設定の保存に対応し、Service WorkerのキャッシュをVETA15に更新しました。学習・メダル・プロフィールなど既存の保存キーは維持します。

## 「未設定」「未判定」の調査

| 表記 | ソースコード内の文字列の出現数 | 主な用途 |
|---|---:|---|
| 未設定 | 23箇所 | プロフィール未登録、任意の管理番号が空欄、旧記録の表示代替など |
| 未判定 | 6箇所 | マイク回答が記録できなかった場合、スキップ・未回答時、記録表・Excelへの表示など |

この数字は **画面に出る表記のコード出現数** です。実際に「未設定」のユーザー数や「未判定」の回答数を示すものではありません。利用者の端末にある保存データはこの配布物には入っていないため、実件数は未確認です。
