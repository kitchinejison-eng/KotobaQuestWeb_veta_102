# ことばクエスト VETA14 — PC・ブラウザ用

VETA13を基準にしたアップデート版です。既存のトレーニング記録、熟練度、メダル、プロフィールのブラウザ内データは保持します。

## 今回の変更

1. ジャンル画面で出題数（5/10/15/20）とヒントの表示を設定できるようにしました。全体設定にも同じ項目を残しています。構音筋ナビなど、課題固有の固定出題数は優先します。
2. 設定内の重複した「ユーザー設定」区画と「音声を使う」を削除。音声読み上げは「読み上げ音声を使う」で一括ON/OFF。マイクでの回答機能は削除していません。
3. 青・赤・黄に緑と紫の画面色を追加し、ゲーム画面にも設定を反映します。
4. レベル選択に、実際に解放済みのLv.のみ表示します。結果画面には熟練度の進捗バーを表示します。全ジャンルの100問×Lv.1〜10の問題バンクと個別学習モードはVETA13から継承します。
5. ことばファンタジーの名前を共通プロフィールに合わせ、通常の戦闘ダメージ音をWeb Audioで再生します。会話イベントの進行・スキップ・縦横対応は既存の修正を引き継ぎます。
6. 3Dピクトグラムは常時ダッシュで、草原のNPC（立ち絵・3D動物）が歩き回るようにしました。
7. コトバ・ダンジョンは初回にアバターだけ選択。名前は共通プロフィールから読み取り、ダンジョン内で変更すると共通プロフィールにも反映します。アバターの中央配置を調整しました。
8. ダンジョンのホームにも既存音源のBGMを再生。ブラウザが自動再生を禁止した場合は、最初のタップで再生を試みます。設定したBGMのON/OFF・音量を優先し、画面を閉じても設定を勝手にOFFにしません。
9. ガチャをドット絵風UIに再構成しました。1回5枚・10連50枚、宝箱演出、スキップ、4段階のレア度、10連結果一覧、景品のコレクション保存に対応。重複した景品は星のかけらになります。

## ファイルの使い方

- **フル版ZIP**：展開したファイルを同じ階層に配置し、`index.html`から起動してください。GitHub Pagesでは展開内容をリポジトリの公開ルートに配置してください。
- **差し替え版ZIP**：VETA13と同じディレクトリに展開し、同名ファイルを上書きしてください。新しい`veta14-*.css/js`ファイルも追加します。変更前にVETA13のバックアップをおすすめします。
- ブラウザで古い画面が残る場合、更新後に再読み込みしてください。Service Workerキャッシュ名はVETA14へ更新済みです。
- 利用者データはブラウザのlocalStorageにあるため、ブラウザのデータ消去はしないでください。別端末へ自動同期はしません。

## テスト

```
node tests/verify-veta11.cjs
node tests/verify-veta12.cjs
node tests/verify-veta13.cjs
node tests/verify-veta14.cjs
```

ブラウザ用の追加テスト `tests/verify-veta14-browser.cjs` は、ローカルサーバーとPlaywright/Chromiumが利用可能な環境で実行できます。この作業環境ではブラウザの起動権限がないため、実機のタッチ操作、音声再生、3D描画は最終確認が必要です。

※ 今回は**PC・ブラウザ版**の更新です。Android APKの再ビルド・実機クラッシュ修正は含みません。
